# BodyCam

BodyCam is a *iOS* app that was made to adds a clipping feature. This Project was incomplete/abandoned as I lost interest. However, only the UI and some of the extra features are left incomplete. The clipping function is functional, feel free to use.

## How to use/run
+ Download/Clone this into Xcode
+ Run the app on your iOS device

## What I have learned from BodyCam
+ Relearned bits of Swift.
+ Learned how to make custom UI for iOS.
